# Ellada

A creator platform where every message is labelled with who really wrote it.

This repo holds the investor prototype: a one-page pitch plus a clickable phone app demo, in a single `index.html` with no build step.

## Run it

Open `index.html` in any browser. To share it as a website, enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root).

## What the prototype shows

- **Labelled chat:** replies written by the creator get a green "Written by" seal; team or AI replies are always marked. Use the Creator / Team switch in Messages to demo it.
- **Defined offers:** fixed-price voice notes, feedback and calls, with automatic refunds if not delivered on time.
- **Fan levels that fade:** levels unlock access (not copyable content) and drop after 30 days of inactivity. Try "Skip 10 days" in My levels.
- **Revenue calculator:** models one creator's earnings at Ellada's 12% commission vs. a 20% cut.

## Status

Prototype only. All creators, numbers and messages are example data. No backend, accounts or payments yet.
